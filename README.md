# schedule-manager 排班管理系统（Web 版）

医院 / 科室排班管理系统，纯浏览器运行，无需 Electron 桌面端、无需后端服务，所有数据保存在浏览器本地。

## 技术栈

- **Vite 5** —— 开发与构建工具
- **Vue 3**（`<script setup>`）+ **TypeScript** —— 前端框架
- **Pinia** —— 状态管理
- **Element Plus** —— UI 组件库（按需自动引入）
- **vuedraggable** —— 拖拽排序（如夜班循环规则）
- **sortablejs** —— 人员列表表格行拖拽排序
- **dayjs** —— 日期处理

## 功能模块

应用采用左侧导航 + 顶部信息栏 + 卡片化内容区的网页布局，覆盖排班全流程：

| 模块 | 说明 |
| --- | --- |
| 本周排班 | 查看 / 手工编辑 / 生成当前周排班，支持添加人员、发布、导出 CSV |
| 下周排班 | 生成排班、复制本周排班、删除排班，支持添加人员、发布、导出 CSV |
| 历史排班 | 按周下拉或选择日期定位，查看已保存的排班记录（只读） |
| 人员管理 | 维护人员档案与状态，支持搜索 / 筛选、拖动行固定排序、夜班组批量设置 |
| 岗位管理 | 维护岗位信息 |
| 班次管理 | 维护班次（名称、时间等） |
| 夜班循环规则 | 配置夜班循环规则，支持拖拽排序 |
| 需求管理 | 维护员工的休息 / 指定班次需求，可手动标记已满足 / 已拒绝 |
| 系统设置 | 应用级配置、数据导入导出、备份、示例数据 |

界面按 Web 应用习惯组织：左侧深色导航支持收起 / 展开，顶部栏显示当前页面、日期、周次、在册人员与待处理需求；内容区以白色卡片承载工具栏与表格，并针对窄屏自动收起侧栏、隐藏次要指标。

删除类操作均通过统一的确认弹窗（`ElMessageBox.confirm`）进行二次确认；
涉及引用关系的删除（班次 / 岗位 / 人员）会提示影响范围并自动级联清理引用。

### 排班规则说明

- **夜班循环**：夜班组员工按规则顺序循环，每天整体向后轮换一格，保证公平轮转；
  周末自动跳过「助夜班」；规则中的「休息」项表示该员工当天休息。
  校验器会报告夜班人员被安排到循环规则之外的班次，以及周末误排助夜班的情况。
- **必备班次**：可为工作日 / 周末分别配置必备班次，生成时自动补人并逐日轮换；
  校验器会报告缺失的必备班次。
- **需求**：生成 / 复制上周时会自动应用员工的休息或指定班次需求，并把满足的需求标记为「已满足」。
- **数据来源周**：复制排班与生成排班的参照周始终是**目标周的前一周**——
  在「下周排班」页即本周（正在执行的排班），在「本周排班」页即上一个自然周。
  夜班循环也从该周的最后一个夜班之后继续，保证跨周衔接。
- **员工状态**：休假 / 进修 / 停职为临时状态，超过「状态结束时间」后自动恢复可排班；
  离职为永久状态。
- **发布**：排班发布后为只读，防止误改；跨周后自动标记为「已过期」。
- **历史排班镜像**：发布时立即把该周排班、人员名单（含状态与状态时间）、班次、岗位深拷贝为
  不可变镜像；未发布的周在该周结束后按当时内容自动补归档，已有镜像不覆盖。
  历史页只读取镜像，不随当前人员状态 / 班次名称变化。镜像存于 `history_snapshots.json`，
  并自动包含在每日备份与 JSON 导入导出数据包中。
- **人员排序与状态**：人员管理里拖动「排序」列即可固定顺序，排班表按该顺序正序显示；
  排班表始终列出全部人员，没有排班记录的人显示为空行；状态不是「在职」时显示对应状态
  （「其他」显示填写的内容，未填写则显示「其他」）。姓名列只显示状态，不带天数。
- **状态剩余天数**：日期单元格按各自列日期分别计算，`N = 状态结束日 − 该列日期`（自然日差）。
  列日期取自 `ScheduleWeek.weekStart` 经 `getWeekDates()` 展开的 7 个 `YYYY-MM-DD` 字符串，
  排班记录以 `staffId + date` 精确匹配 `ScheduleDetail.date`（同格式）；某天没有排班记录仍照常显示。
  `N > 0` 显示「状态（剩余 N 天）」，`N = 0` 显示「状态（剩余 0 天）」，
  `N < 0` 显示「状态（已结束 N 天）」；历史列按该日回溯计算、今日列即当前剩余、未来列显示到那天时的剩余。
  跨月 / 跨年 / 闰年由日历天数自动处理；在职、状态开始或结束时间缺失 / 非法、
  结束早于开始、列日期缺失 / 非法时均不追加天数，只显示状态。
  状态已结束（`N < 0`）的日期不再用状态占位，改为普通排班单元格，
  在可编辑的周（本周今天及以后、下周）可手动点击配置排班；只读视图不可编辑。
  CSV 导出同步输出这些日期的实际班次。
- **备注显示**：选择班次时可填写备注并指定文字颜色（默认与表格字体颜色一致）；备注不为空时
  单元格显示为「班次（备注）」并使用所选颜色，导出 CSV 保留括号文本（不含颜色）。
- **夜班组**：人员管理工具栏「夜班组」弹窗列出当前可用人员，勾选的设为夜班组、未勾选的设为白班组。
- **规则校验**：只检查每日必备班次是否齐全、夜班人员是否按循环规则排班（含周末不排助夜班）；
  不再检测班次时间重叠或跨天时间冲突。

## 环境要求

- Node.js 18+（建议 20 LTS）
- npm 9+

## 开发 / 构建

```bash
# 安装依赖
npm install

# 启动开发模式（默认 http://localhost:5173，带热重载）
npm run dev

# 类型检查
npm run typecheck

# 打包生产版本（输出 dist/，可直接部署到任意静态站点）
npm run build

# 预览生产构建
npm run preview
```

## 数据存储

数据保存在浏览器 `localStorage`，按数据文件分键存储，启动时自动初始化默认结构。
`src/storage/index.ts` 对上层提供统一的 `storage` 接口：

- `read(fileName)` / `write(fileName, data)` —— 读写数据文件；写入前保留上一份副本，读取失败时自动回退
- `backup()` —— 按日期保存快照，仅保留最近 7 天；应用启动时自动执行一次
- `exportBundle()` —— 打包全部数据为 JSON 文件并触发浏览器下载
- `importBundle()` —— 通过文件选择框读取 JSON，结构校验通过后先备份再覆盖现有数据

> 数据只属于当前浏览器、当前站点：清除浏览器数据、更换浏览器或域名都会导致数据不可见。
> 请定期使用「导出数据」保存 JSON 备份；`localStorage` 通常有约 5MB 容量限制。

## 项目结构

```
index.html            # Vite 入口
vite.config.ts        # 构建配置（@ 指向 src）
src/
├── main.ts           # 应用入口，初始化本地存储
├── App.vue           # 侧边导航、顶部栏与页面切换
├── styles.css        # 设计令牌、布局与组件美化样式
├── storage/          # 浏览器持久化、备份、导入导出
├── views/            # 各功能页（本周/下周排班、人员、岗位、班次…）
├── components/       # 业务组件（列表、表单弹窗、排班表格等）
├── core/             # 纯逻辑：排班生成、规则校验、CSV 导出、反馈封装
├── stores/           # Pinia 状态（useStaffStore 等）
├── types/            # TypeScript 类型定义
└── constants/        # 常量（数据文件名、状态与分组等枚举标签）
```

## 说明

- 组件与 API 经 `unplugin-vue-components` / `unplugin-auto-import` 按需自动引入，无需手动 `import` 组件。
- 主色、圆角、阴影、卡片与表格样式在 `src/styles.css` 中通过设计令牌统一配置；确认弹窗沿用同一套视觉风格。
